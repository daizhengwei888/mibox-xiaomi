谜盒是给手机读网页准备的划词笔记工具。

在手机上读文章，看到想留的段落，往往只能截图或复制到备忘录，过几天就找不到出处了。电脑上靠右键菜单和快捷键解决的事，手机上没有。

用法很简单：在小米浏览器里长按选中一段文字，屏幕底部会弹出一排按钮：存笔记、解释、翻译、复制。点「存笔记」，原文连同网页标题和链接一起保存；点「解释」或「翻译」，结果直接显示在页面里，不用切换 App。

晚上看长文时，点右下角的小胶囊，可以切换暖纸、夜读、墨水屏三种阅读模式，也能调大字号。已经打开的标签页会一起切换。

其他功能：
· 收藏网页时自动生成一句话简介和预计阅读时长
· 屏蔽网页里的广告图片，省流量
· 本地加密保险箱（AES-256-GCM），存放常用账号密码

所有数据只保存在本机，不需要注册。不填 API Key 时，解释和要点由本地规则生成，离线也能用；填入 MiMo 等兼容接口的 Key 后，交给大模型处理。

手机上按单手操作设计，平板上自动切换为宽屏布局。
